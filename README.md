# Communication PhD Program Explorer

Find US Communication / Media / Journalism PhD programs and faculty that match your research. Matching runs in the browser (Transformers.js + `bge-small-en-v1.5`); the site is static and deployed to GitHub Pages.

Live: https://junyu-jiang0508.github.io/communication_phd/

Modeled on the [Political Science Program Explorer](https://political-science-program-explorer.vw9pwn.chatgpt.site/); see `docs/PLAN.md` for the breakdown of that site's logic and what this one changes.

## Layout

```
pipeline/            Python data pipeline (fetch helper, schemas, validators, build.py, taxonomy.json)
data/                programs_seed.json → programs_discovered.json → programs.json; raw/<slug>.json; labels/<slug>.json
  cache/             symlink → ~/data/communication_phd/data/cache (fetched HTML, photo cache, audits; not in git)
src/                 Astro 5 site (no framework islands; vanilla TS)
  data/              generated by pipeline/build.py (programs, faculty, bios, taxonomy, meta)
  lib/               match.ts (embeddings + BM25 + hints), ui.ts, i18n.ts, shortlist.ts
  pages/             index (Match), programs/, faculty/, shortlist, about
public/search/       manifest.json, index.json, vectors.i8.bin (int8 faculty embeddings)
public/faculty/      112px WebP portraits · public/schools/ favicons · public/fonts/ self-hosted type
docs/                PLAN.md, design-brief.md
```

## Commands

```bash
npm install && npm run dev        # local site at localhost:4321/communication_phd/
npm run build                     # static output in dist/

# data pipeline (conda env "nlp": sentence-transformers, playwright, Pillow, bs4)
python pipeline/validate_raw.py data/raw/*.json
python pipeline/validate_labels.py data/labels/*.json
python pipeline/prefetch_photos.py   # warm the photo cache (build.py reads photos only from it)
python pipeline/build.py          # → src/data, public/search, public/faculty, public/schools
```

Deploy: push to `main`; `.github/workflows/deploy.yml` builds and publishes to GitHub Pages.
